## 1) Wireframe (Page Layout)

[Header]
- Brand/Logo (Vivo X710)
- Nav links: Features | Details | Pricing

[Hero Section]
- Large product image (white phone)
- Product title + 1–2 line description
- CTA button: "أضف إلى السلة"
- Rating / short trust line

[Features Section]
- 4 cards (Grid)
  1) Display
  2) Camera
  3) Selfie
  4) Performance

[Details Section]
- Longer description
- Specs list (with icons)
- Logistics: Shipping + Return policy
- Trust: FAQ (2 questions)

[Pricing / Offer]
- Price in JOD
- Old price + new price (discount)
- CTA button: "اشترِ الآن"

[Footer]
- Brand name
- Copyright
- Useful links

## 2) Plan (Step-by-step)

1. Create project structure:
   - index.html
   - styles.css
   - assets/ (images)
2. Build HTML structure first:
   - Header, Hero, Features, Details, Pricing, Footer
   - Add ids for anchor links (#features, #details, #pricing)
3. Apply layout:
   - Use Flexbox for header alignment + buttons
   - Use Grid for cards/specs and page sections
4. Styling:
   - Choose consistent colors, spacing, typography
   - Add hover effects on buttons/cards/images
5. Responsive:
   - Add media queries for tablet/mobile
   - Stack grids into 1 column on small screens
6. Content refinement:
   - Add clear product specs + shipping/return + FAQ
   - Ensure one clear CTA in hero and another in pricing
7. Deployment:
   - Push to GitHub
   - Deploy using GitHub Pages
   - Test live link and fix any broken assets paths
